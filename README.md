# VERDORA — AI Brand Identity Kit

**Tagline:** Small Choices. Greener Futures.

## Project Overview
VERDORA is a sustainable lifestyle brand identity project created using AI-assisted design. It focuses on building a consistent, natural, modern, and trustworthy visual identity.
